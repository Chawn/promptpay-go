# Contributing

Thanks for helping! This project is maintained by [Chawn](https://github.com/Chawn).

## Ground rules
- Open an issue before large changes so we can agree on the API first.
- Every behaviour change needs tests. Every bug fix needs a regression test.
- Keep the public API small. Prefer adding a function over adding a flag.
- No new runtime dependencies without discussion in an issue.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:` ...).
